#  Amazon Prime Video Dashboard

An interactive Power BI dashboard built using the Amazon Prime Video dataset to analyze content distribution, genres, ratings, release years, and directors.

##  Dashboard Preview

![Dashboard](Amazon_Prime_Dashboard_.png)

---

##  Features

-  Total Titles
-  Total Ratings
-  Total Genres
-  Total Directors
-  Start Year & End Year
-  Ratings by Total Shows
-  Genres by Total Shows
-  Movies vs TV Shows
-  Release Year Trend
-  Country-wise Distribution

---

##  Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

---

##  Dataset

- Amazon Prime Titles Dataset (.xlsx)
